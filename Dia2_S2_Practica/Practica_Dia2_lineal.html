Recordatorio: modelos independientes y modelo común

Con un modelo por región \(r\):

\[ \log\delta_{ir} = \mathbf{x}_{ir}^\top\boldsymbol\beta_r + \varepsilon_{ir}, \qquad \varepsilon_{ir} \sim N(0, \sigma_r^2), \]

cada región tiene sus propios \(\boldsymbol\beta_r\) y \(\sigma_r\). Un modelo común impone \(\boldsymbol\beta_r = \boldsymbol\beta\) para todas.

Entre ambos extremos está el modelo jerárquico: \(\boldsymbol\beta_r \sim N(\boldsymbol\beta, \boldsymbol\Sigma)\), que comparte información entre regiones y deja que difieran. La comparación de los \(\boldsymbol\beta_r\) ajustados por separado orienta hipótesis para comparar modelos; no basta para elegir una estructura nacional.

ajustar_lineal <- function(datos, seed) {
  aptos <- datos %>% filter(apto_modelo)
  X <- construir_X(aptos)
  stopifnot(all(is.finite(X)), all(is.finite(aptos$delta)), all(aptos$delta > 0),
            nrow(X) > ncol(X), qr(X)$rank == ncol(X))
  fit <- sampling(modelo_lineal,
                  data = list(n = nrow(X), p = ncol(X), X = X, y = log(aptos$delta), sd_beta = 1),
                  chains = 4, iter = 2000, warmup = 1000, seed = seed, refresh = 0, pars = c("beta", "sigma"))
  fit
}

Recordatorio: validación cruzada dejando uno fuera

La capacidad predictiva fuera de muestra se mide con la densidad predictiva logarítmica esperada:

\[ \text{elpd}_{\text{loo}} = \sum_{i=1}^n \log p(y_i \mid \mathbf{y}_{-i}), \qquad p(y_i \mid \mathbf{y}_{-i}) = \int p(y_i \mid \boldsymbol\theta)\,p(\boldsymbol\theta \mid \mathbf{y}_{-i})\,d\boldsymbol\theta. \]

Reajustar el modelo \(n\) veces puede ser costoso; PSIS-LOO lo aproxima con los draws de un solo ajuste mediante muestreo por importancia:

\[ p(y_i \mid \mathbf{y}_{-i}) \approx \frac{\sum_s w_i^{(s)}\,p(y_i \mid \boldsymbol\theta^{(s)})}{\sum_s w_i^{(s)}}, \qquad w_i^{(s)} \propto \frac{1}{p(y_i \mid \boldsymbol\theta^{(s)})}, \]

con pesos suavizados por una distribución de Pareto. El umbral de Pareto-k depende del número de draws: \(\min(1-1/\log_{10}S,\ 0{,}7)\). Revise las observaciones señaladas y, si procede, use reajustes LOO exactos o validación cruzada K-fold antes de adoptar el ranking.

Solución 2: LOO

log_lik_lineal <- function(fit, X) {
  beta <- as.matrix(fit, pars = "beta"); sigma <- as.matrix(fit, pars = "sigma")[, 1]
  mu <- beta %*% t(X)                                       # draws x segmentos
  dnorm(matrix(y, nrow(mu), ncol(mu), byrow = TRUE), mu, sigma, log = TRUE)
}
compute_loo <- function(log_lik, fit) {
  dims <- dim(as.array(fit, pars = "beta"))
  chain_id <- rep(seq_len(dims[2]), each = dims[1])
  scaled_likelihood <- exp(sweep(log_lik, 2, apply(log_lik, 2, max), "-"))
  r_eff <- loo::relative_eff(scaled_likelihood, chain_id = chain_id, cores = 2)
  loo::loo(log_lik, r_eff = r_eff, cores = 2)
}

Recordatorio: heterocedasticidad por grupo

\[ y_i \mid \boldsymbol\beta, \boldsymbol\sigma \sim N\big(\mathbf{x}_i^\top\boldsymbol\beta,\ \sigma^2_{z[i]}\big), \qquad z[i] \in \{1, 2, 3\}. \]

En Stan, sigma[zona] construye un vector con la \(\sigma\) de la zona de cada segmento (indexación múltiple):

// Regresion lineal con una desviacion estandar distinta por zona
data {
  int<lower=1> n;
  int<lower=1> p;
  matrix[n, p] X;
  vector[n] y;                               // log(delta_i)
  int<lower=1> J;                            // numero de zonas
  array[n] int<lower=1, upper=J> zona;       // zona de cada segmento
}
parameters {
  vector[p] beta;
  vector<lower=0>[J] sigma;                  // una sigma por zona
}
model {
  beta ~ normal(0, 1);
  sigma ~ cauchy(0, 2.5);
  y ~ normal(X * beta, sigma[zona]);         // indexacion: sigma de la zona de cada segmento
}
generated quantities {
  array[n] real y_rep = normal_rng(X * beta, sigma[zona]);
  vector[n] log_lik;
  for (i in 1:n) log_lik[i] = normal_lpdf(y[i] | X[i] * beta, sigma[zona[i]]);
}

Ejercicio 4 (extensión): población implícita con viviendas observadas

Ejercicio 4

  1. Con el modelo B ajustado en Aysén, simule la predictiva posterior de \(\delta_i\) para todos los segmentos, aptos y no aptos.
  2. Calcule en cada draw la población implícita \(\hat Y_i = \hat\delta_i \times V_i\) con las viviendas ocupadas observadas, y súmela por clasificación de cobertura.
  3. Compare con las personas censadas. ¿Dónde aumenta o disminuye el total implícito? ¿Qué supuestos condicionan esa diferencia?
  4. ¿Qué pasa con los segmentos con \(V_i = 0\)? ¿Qué información faltaría para corregir la subcobertura de viviendas?

Recordatorio: totales por draw

Para un conjunto de segmentos \(A\):

\[ T_A^{(s)} = \sum_{i \in A} \hat\delta_i^{(s)} V_i, \qquad \hat\delta_i^{(s)} = \exp\big(\mathbf{x}_i^\top\boldsymbol\beta^{(s)} + \sigma^{(s)}\varepsilon_i^{(s)}\big). \]

  • Se suma dentro de cada draw y luego se resumen los \(T_A^{(s)}\).
  • Estos son totales implícitos continuos bajo un modelo de densidad. No incluyen una nueva simulación Poisson de personas ni constituyen una estimación validada de omisión censal.
  • Si \(V_i = 0\), \(\hat Y_i = 0\) en todos los draws: la fórmula aporta una densidad modelada, pero no identifica las viviendas faltantes.

Solución 4: discusión

  • Con \(\hat Y_i = \hat\delta_i V_i\) y las viviendas observadas, se obtiene un total condicionado a esas viviendas: la diferencia con el censo no demuestra una corrección válida de omisión.
  • Los segmentos con \(V_i = 0\) quedan con población predicha 0.
  • Para corregir la subcobertura hace falta ajustar la exposición: \(V_i^{tot} = V_i / c_i\), con \(c_i\) la cobertura de viviendas del segmento. La división requiere cobertura positiva y una definición operativa validada; con cobertura cero hace falta otra fuente de exposición. Su uso se revisará en el modelo de Chile (días 3 y 4).

Ejercicio 5: chequeo predictivo previo

Ejercicio 5

Antes de ver los datos, ¿qué densidades considera plausibles el modelo?

  1. Simule 200 valores de \(\boldsymbol\beta\) desde la previa \(N(0, 1)\) y de \(\sigma\) desde una \(\text{Cauchy}^+(0; 2{,}5)\).
  2. Para cada simulación, calcule \(\delta_i = \exp(\mathbf{x}_i^\top\boldsymbol\beta + \sigma\varepsilon_i)\) en los segmentos de Aysén.
  3. ¿Qué proporción de los \(\delta_i\) simulados es mayor que 20 o menor que 1 persona por vivienda?
  4. Repita con \(\beta_k \sim N(0; 0{,}2^2)\), \(\beta_0 \sim N(\log 2{,}5;\ 0{,}5^2)\) y \(\sigma \sim N^+(0; 0{,}5^2)\).

Recordatorio: la predictiva previa

\[ p(\mathbf{y}) = \int p(\mathbf{y} \mid \boldsymbol\theta)\,p(\boldsymbol\theta)\,d\boldsymbol\theta. \]

Simular de la predictiva previa (primero \(\boldsymbol\theta \sim p(\boldsymbol\theta)\), luego \(\mathbf{y} \sim p(\mathbf{y} \mid \boldsymbol\theta)\)) muestra qué datos considera plausibles el modelo antes de observarlos (Gabry et al. 2019).

  • Con 13 coeficientes \(N(0, 1)\) y covariables estandarizadas, \(\text{Var}(\mathbf{x}_i^\top\boldsymbol\beta) = \sum_k x_{ik}^2\): el predictor lineal puede ser enorme en segmentos con covariables extremas.
  • Una previa que implica densidades de miles de personas por vivienda es poco realista, y su influencia posterior debe comprobarse, sin descartarla solo por tener muchos segmentos.

simular_previa <- function(sd_beta, media_b0, sd_b0, sim_sigma, seed, n_sim = 200) {
  set.seed(seed)
  map_dfr(1:n_sim, function(s) {
    beta <- c(rnorm(1, media_b0, sd_b0), rnorm(ncol(X_todos) - 1, 0, sd_beta))
    sigma <- sim_sigma()
    tibble(log_delta = drop(X_todos %*% beta) + rnorm(nrow(X_todos), 0, sigma))
  })
}

  • Las diferencias entre regiones se evalúan mediante distribuciones de diferencias y comparación predictiva; un cambio de signo no impone un modelo por región.
  • LOO compara modelos por su capacidad de predecir segmentos nuevos; revise los \(\hat k\) de Pareto.
  • La variabilidad no explicada puede depender de la zona; la indexación sigma[zona] en Stan lo permite.
  • Predecir \(\delta_i\) no basta: con \(V_i\) observado no se corrige la subcobertura de viviendas.
  • Revise siempre qué implican las previas en la escala de los datos.
