Ejercicio 1: proporción de segmentos con viviendas colectivas

Ejercicio 1

La variable n_vc > 0 identifica segmentos con viviendas colectivas (hospitales, cuarteles, residencias). No debe confundirse automáticamente con excluido_colectivo, que es el indicador usado por el filtro del modelo.

La proporción de este conjunto observado se calcula directamente; aquí se usa como ejemplo para inferir una probabilidad Bernoulli para segmentos comparables.

  1. Calcule la posterior de la proporción \(\theta\) de segmentos de Magallanes con al menos una vivienda colectiva (n_vc > 0), con una previa \(\text{Beta}(1, 1)\): primero en forma analítica y luego con stan/bernoulli_beta.stan.
  2. Reporte la media posterior y el intervalo de credibilidad al 95%.
  3. Repita con una previa \(\text{Beta}(1, 99)\) (se espera cerca de 1% de segmentos). ¿Cambia la conclusión? ¿Por qué?

Recordatorio: Bernoulli–Beta

\[ \theta \mid \mathbf{y} \sim \text{Beta}(a + s,\ b + n - s), \qquad E(\theta \mid \mathbf{y}) = \frac{a + s}{a + b + n}. \]

La previa \(\text{Beta}(1, 99)\) tiene media \(0{,}01\) y tiene concentración \(a + b = 100\); esta analogía con pseudoconteos no representa observaciones reales. El peso de los datos es

\[ w = \frac{n}{a + b + n} = \frac{3.044}{100 + 3.044} = 0,968. \]

Recordatorio: funciones de parámetros independientes

La factorización siguiente supone verosimilitudes independientes y previas independientes, sin parámetros compartidos entre regiones. Tener datos distintos por sí solo no garantiza independencia posterior:

\[ p(\delta_M, \delta_A \mid \mathbf{Y}_M, \mathbf{Y}_A) = p(\delta_M \mid \mathbf{Y}_M)\,p(\delta_A \mid \mathbf{Y}_A). \]

Si \(\delta_M^{(s)}\) y \(\delta_A^{(s)}\) son draws de cada posterior, \(\Delta^{(s)} = \delta_M^{(s)} - \delta_A^{(s)}\) son draws de la posterior de la diferencia, y

\[ \Pr(\delta_M > \delta_A \mid \mathbf{Y}) \approx \frac{1}{S}\sum_{s=1}^S \mathbb{1}\big(\Delta^{(s)} > 0\big). \]

Analíticamente, \(E(\Delta) = \frac{a_M'}{b_M'} - \frac{a_A'}{b_A'}\) y \(\text{Var}(\Delta) = \frac{a_M'}{b_M'^2} + \frac{a_A'}{b_A'^2}\).

Recordatorio: la razón de medianas

Como en el ejercicio 2, los ajustes por zona suponen verosimilitudes y previas independientes, sin parámetros compartidos.

Si \(\log\delta \sim N(\mu, \sigma^2)\), la mediana de \(\delta\) es \(e^{\mu}\). La razón de medianas entre zonas es

\[ \rho = \frac{e^{\mu_U}}{e^{\mu_R}} = e^{\mu_U - \mu_R}, \]

y sus draws son \(\rho^{(s)} = e^{\mu_U^{(s)} - \mu_R^{(s)}}\).

  • \(\rho > 1\): la mediana modelada de personas por vivienda es mayor en la zona urbana. No implica que todos sus segmentos superen a los rurales.
  • La transformación \(e^{x}\) es monótona: los cuantiles de \(\rho\) son \(e^{(\text{cuantiles de } \mu_U - \mu_R)}\).

Recordatorio: marginales de la Dirichlet

Con \(\boldsymbol\theta \mid \mathbf{y} \sim \text{Dirichlet}(\alpha'_1, \alpha'_2, \alpha'_3)\) y \(\alpha'_0 = \sum_k \alpha'_k\):

\[ \theta_k \mid \mathbf{y} \sim \text{Beta}(\alpha'_k,\ \alpha'_0 - \alpha'_k), \qquad \Pr(\theta_{\text{urbana}} > 0{,}75 \mid \mathbf{y}) = 1 - F_{\text{Beta}(\alpha'_U,\ \alpha'_0 - \alpha'_U)}(0{,}75). \]

Con draws: la proporción de draws con \(\theta_{\text{urbana}}^{(s)} > 0{,}75\).

Ejercicio 5 (desafío): Metropolis para la densidad

Ejercicio 5

  1. Programe un algoritmo de Metropolis para el modelo Poisson–Gamma del ejercicio 2 (Magallanes). Trabaje con \(u = \log\delta\) para evitar valores negativos: recuerde sumar el jacobiano a la log-posterior.
  2. Corra 4 cadenas de 5.000 iteraciones desde valores iniciales distintos y descarte las primeras 1.000.
  3. Compare la media posterior con la solución exacta \((a + \sum Y_i)/(b + \sum V_i)\) y calcule \(\hat R\) y el ESS.
  4. Pruebe los tamaños de paso 0,001, 0,01 y 0,05. ¿Cómo cambian la tasa de aceptación y el ESS?

Recordatorio: el jacobiano

Si se muestrea \(u = \log\delta\) en lugar de \(\delta\), la densidad de \(u\) es

\[ p_U(u \mid \mathbf{Y}) = p_\delta\big(e^{u} \mid \mathbf{Y}\big)\left|\frac{d\delta}{du}\right| = p_\delta\big(e^{u} \mid \mathbf{Y}\big)\,e^{u}, \]

y en escala logarítmica

\[ \log p_U(u \mid \mathbf{Y}) = \log p(\mathbf{Y} \mid e^u) + \log p(e^u) + u + \text{constante}. \]

Olvidar el término \(+u\) produce una cadena que converge a una distribución equivocada.

Solución 5: el algoritmo

log_post <- function(log_d, y, v, a = 0.01, b = 0.01) {
  d <- exp(log_d)
  sum(dpois(y, d * v, log = TRUE)) + dgamma(d, a, b, log = TRUE) + log_d   # + jacobiano
}
metropolis_pg <- function(inicio, y, v, n_iter = 5000, paso = 0.01) {
  cadena <- numeric(n_iter); accepted <- logical(n_iter)
  actual <- inicio; lp <- log_post(actual, y, v)
  for (t in 1:n_iter) {
    prop <- actual + rnorm(1, 0, paso); lp_prop <- log_post(prop, y, v)
    if (is.finite(lp_prop) && log(runif(1)) < lp_prop - lp) {
      actual <- prop; lp <- lp_prop; accepted[t] <- TRUE
    }
    cadena[t] <- actual
  }
  draws <- exp(cadena)
  attr(draws, "accepted") <- accepted
  draws
}

Para llevar

  • Los modelos conjugados permiten verificar que Stan entrega la posterior correcta.
  • Las funciones de parámetros (diferencias, razones, probabilidades) se obtienen directamente de los draws.
  • Una única densidad por región no reproduce la variabilidad entre segmentos: hay sobredispersión.
  • La densidad y su variabilidad difieren entre zonas: la zona es una covariable natural del modelo.
  • Un algoritmo MCMC mal ajustado converge lento: hay que revisar \(\hat R\), ESS y la tasa de aceptación.
